# Sirius Biotech Summit

Исходный код приложения события, веб-версии и панели организатора. Репозиторий предназначен для совместной разработки и обсуждения изменений через issues и pull requests.

## Состав

- `server/` — FastAPI, API, панель организатора, очередь писем и тесты.
- `web/src/` — интерфейс веб-приложения; `web/navigator/` — мост к навигатору.
- `app/src/` — код Android-клиента и его взаимодействия с API.
- `navigator/src/` — исходный код навигатора.
- `shared/` — общая конфигурация и обработка фотографий.
- `scripts/` — оставленные сценарии сборки и подготовки; некоторые требуют локальных входных файлов, которых нет в репозитории.

## Локальный запуск сервера

Нужны Python 3.12+ и зависимости из `server/requirements-test.txt`. Из корня репозитория:

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r server/requirements-test.txt
export ADMIN_CODE="$(python -c 'import secrets; print(secrets.token_urlsafe(32))')"
export PIN_LOOKUP_SECRET="$(python -c 'import secrets; print(secrets.token_urlsafe(32))')"
export DATABASE_PATH="$PWD/local.sqlite3"
export COOKIE_SECURE=false
PYTHONPATH=server uvicorn main:app --host 127.0.0.1 --port 8080
```

Панель: `http://127.0.0.1:8080/admin`. Для входа используйте значение `ADMIN_CODE`, заданное в текущем терминале. Переменные и локальная база не предназначены для публикации. Укажите постоянные секреты для повторного запуска с сохранением доступа к базе. Тесты: `PYTHONPATH=server pytest -q server/tests`.

## Ограничения сборки

Здесь опубликован очищенный набор исходников, а не полный воспроизводимый Android/PWA build. Оригинальные восстановленные компоненты MSS, DEX/APK и иные двоичные зависимости, исходные материалы и данные площадки, радиокарты и записи навигатора не включены. Скрипты сохранены для понимания процесса, но без этих входных материалов сборка Android и карты не завершится. Право распространения сторонних материалов и возможность передачи их команде необходимо отдельно подтвердить владельцу. Продакшен-ключ подписи, базы, загруженные фотографии и секреты сюда не входят.

В копии Android-кода адрес по умолчанию специально заменён на `https://example.invalid`, чтобы разработка не обращалась случайно к рабочему серверу. Для тестирования используйте свой сервер.

Данные в `server/fixtures/` — архивные и адаптированные материалы программы; не считать их утверждённой программой 2027 года. Не публикуйте персональные данные участников, реальные коды входа, токены, файлы `.env`, базы и бэкапы. Не производите нагрузочные и изменяющие тесты на рабочем сервере.

## Как внести вклад

Создайте ветку, опишите задачу и откройте pull request с кратким описанием и результатами проверок. При изменениях API, авторизации, доступа к участникам или фотографиям добавляйте проверки прав и совместимости клиентов. Лицензия на распространение кода и сторонних материалов отдельно не определена; согласуйте использование с владельцем проекта.
